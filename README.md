# Саша и Соня

Наш общий архив и планы: моменты, вишлисты, планирование и статистика переписки.

Сайт: **https://dogking411.github.io/OurSiteSs/**

## Что уже работает

- **Вишлисты** — два списка, свой и второй половины. Можно забронировать подарок
  из чужого списка: владелец этого не увидит.
- **Моменты** — архив: что было, когда, где, с фотографиями и тегами.
- **Саша и Соня** — кто ты, сайт узнаёт из аккаунта: спрашивает один раз при
  первом входе и дальше помнит. От этого зависят цвета и то, чей список твой.
- **Общие данные** — всё лежит в облаке: что сохранил один, сразу видит второй.

## В работе

- **Планы** — раздел-заглушка, данные уже умеют храниться.
- **Статистика переписки** — раздел-заглушка; разбор выгрузки будет идти в
  браузере, без отправки переписки куда-либо.

## Запуск

```bash
npm install
npm run dev
```

Сайту нужен доступ к облаку: создай файл `.env` по образцу `.env.example`. Без
него откроется экран первой настройки, где адрес и ключ можно ввести руками.
Как завести проект — [docs/SUPABASE.md](docs/SUPABASE.md).

Сборка: `npm run build`, результат в `dist/`. Проверка типов: `npm run typecheck`.

## Публикация

Пуш в `main` публикует сайт через GitHub Actions. Настройки облака берутся из
секретов репозитория — см. [docs/SUPABASE.md](docs/SUPABASE.md).
