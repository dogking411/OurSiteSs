# Саша и Соня

Наш общий архив и планы: моменты, вишлисты, планирование и статистика переписки.

## Что уже работает

- **Вишлисты** — два списка, свой и второй половины. Можно забронировать подарок
  из чужого списка: владелец этого не увидит.
- **Моменты** — архив: что было, когда, где, с фотографиями и тегами.
- **Профиль Саша / Соня** — переключается в настройках, меняет оформление и то,
  чей список открывается первым.
- **Два режима хранения** — локально в браузере (без настройки) или в общем
  облаке (данные синхронизируются между вами).

## В работе

- **Планы** — раздел-заглушка, данные уже умеют храниться.
- **Статистика переписки** — раздел-заглушка; разбор выгрузки будет идти в
  браузере, без отправки переписки куда-либо.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:5173 и сразу заработает в локальном режиме.

Сборка: `npm run build`, результат в `dist/`. Проверка типов: `npm run typecheck`.

## Публикация

Пуш в `main` публикует сайт через GitHub Actions. Один раз нужно включить это в
репозитории: **Settings → Pages → Source → GitHub Actions**.

## Общие данные

Пока облако не подключено, у тебя и у Сони будут разные списки: локальный режим
хранит данные в конкретном браузере. Как сделать их общими —
[docs/SUPABASE.md](docs/SUPABASE.md), примерно 15 минут.
